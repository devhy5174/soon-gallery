SOON GALLERY — Project Guidelines

1. 프로젝트 개요

SOON GALLERY는 한국 전통 문인화 작품을 감상할 수 있는 3D 메타버스 온라인 전시관이다.

실제 미술관을 방문한 것처럼 자유롭게 이동하며 작품을 감상할 수 있고, 관리자는 새로운 작품을 직접 등록하고 전시할 수 있다.

핵심 목표

- 실제 미술관 같은 몰입감 있는 3D 전시 공간
- 누구나 로그인 없이 입장할 수 있는 게스트 모드
- 관리자 인증을 통한 작품 등록·수정·삭제
- 작품 방향과 크기에 따른 맞춤형 액자
- 빈 벽면에 작품 자동 배치
- 작품 업데이트 시 재배포 없이 전시관에 반영
- 데스크톱과 모바일 관람 지원

2. 기술 스택

- Frontend: React + TypeScript + Vite
- 3D: Three.js + React Three Fiber + Drei
- Styling: 일반 CSS
- Backend: Supabase (추후 연결)
- Deployment: Netlify

개발 원칙

- 기존 기술 스택을 유지한다.
- 불필요한 외부 라이브러리 설치를 지양한다.
- React 함수형 컴포넌트와 TypeScript를 사용한다.
- 기능별로 컴포넌트와 파일을 분리한다.
- 기존 코드를 수정할 때 다른 기능에 영향을 주지 않도록 한다.

3. 디자인 가이드

콘셉트

한국 전통 문인화와 현대적인 미술관이 조화를 이루는 따뜻하고 고급스러운 공간.

주요 디자인 요소

- 따뜻한 아이보리 벽면
- 밝은 원목 바닥
- 얇고 통일된 원목 액자
- 은은한 천장 레일 조명
- 넓은 여백과 절제된 장식
- 한국적인 분위기를 살린 미니멀 디자인

색상

기존 src/index.css의 CSS 변수를 우선 사용한다.

- Background: #F7F3EB
- Surface: #FFFCF7
- Text: #292724
- Primary: #76563E
- Accent: #A64B3C
- Wall: #F3E9DC
- Wood: #B9916A

디자인 주의사항

- 화려한 색상과 과도한 애니메이션을 피한다.
- 문인화 작품 자체가 돋보이도록 구성한다.
- 전시관 전체의 액자 디자인을 통일한다.
- 기본 디자인은 밝은 테마로 유지한다.
- 3D 공간의 재질과 조명은 Three.js에서 구현한다.

4. 주요 기능

게스트

- 로그인 없이 전시관 입장
- 3D 공간 자유 이동
- 작품 클릭 및 확대 감상
- 작품명과 설명 확인
- 작품 수정 및 삭제 불가

관리자

- 안전한 인증 후 입장
- 작품 이미지 업로드
- 작품명 및 설명 등록
- 액자 방향 선택: 자동 / 가로 / 세로 / 정사각형
- 액자 크기 선택: S / M / L / XL
- 빈 벽면에 작품 자동 배치
- 작품 수정·삭제 및 사진 교체
- 전시 위치 관리

작품 전시 규칙

- 원본 이미지 비율을 최대한 유지한다.
- 이미지가 잘리지 않도록 액자 내부에 배치한다.
- 액자 크기에 따라 실제 3D 공간에서 크기가 달라져야 한다.
- 작품끼리 겹치지 않도록 배치한다.
- 작품 수가 증가해도 확장 가능한 구조로 설계한다.

5. 보안 및 데이터 관리

- 관리자 비밀번호를 프론트엔드 코드에 저장하지 않는다.
- 관리자 인증에는 Supabase Auth를 사용한다.
- Supabase RLS를 통해 관리자만 작품을 변경할 수 있도록 한다.
- 공개 가능한 작품 데이터만 게스트에게 제공한다.
- 비밀키와 관리자 인증 정보는 Git에 커밋하지 않는다.
- 관리자 인증 및 데이터 저장 기능은 별도 개발 단계에서 구현한다.

6. 코드 작성 규칙

- 모든 코드를 App.tsx에 집중시키지 않는다.
- 3D 전시관 관련 코드는 별도 디렉터리로 분리한다.
- 공통 UI는 재사용 가능한 컴포넌트로 작성한다.
- CSS는 역할에 따라 파일을 분리한다.
- 기존 CSS 변수와 디자인 시스템을 우선 활용한다.
- 불필요한 코드와 사용하지 않는 import를 제거한다.
- 기능 구현 후 TypeScript 오류와 빌드 오류를 확인한다.

7. 작업 진행 규칙

- 요청한 기능만 구현하고 불필요하게 범위를 확장하지 않는다.
- 큰 구조 변경이 필요한 경우 먼저 변경 계획을 설명한다.
- 기존에 완성된 디자인과 기능을 임의로 변경하지 않는다.
- 새로운 기능을 추가할 때 기존 기능의 정상 작동 여부를 확인한다.
- 한 번에 모든 기능을 구현하지 않고 단계별로 개발한다.
- 임시 데이터나 테스트 기능은 실제 데이터와 명확히 구분한다.
- 수정 완료 후 변경한 파일과 주요 내용을 간단히 요약한다.

8. 개발 단계

1. 프로젝트 구조 및 입장 화면
1. 3D 전시관 기본 공간
1. 이동 및 작품 감상 기능
1. 액자 크기·방향 및 자동 배치
1. 관리자 작품 등록·관리
1. Supabase 인증 및 데이터 연동
1. 반응형 최적화 및 배포

현재 요청한 개발 단계에 집중하고, 이후 단계의 기능은 명시적으로 요청받았을 때 구현한다.
