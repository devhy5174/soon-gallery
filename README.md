🏛️ SOON GALLERY

먹과 여백이 머무는 공간

SOON GALLERY는 한국 전통 문인화 작품을 감상할 수 있는 3D 메타버스 온라인 전시관입니다.

방문객은 가상 전시관을 자유롭게 돌아다니며 작품을 감상하고, 관리자는 새로운 작품을 등록하고 전시 공간을 관리할 수 있습니다.

🌿 주요 기능

- 3D 전시관 — 실제 미술관처럼 자유롭게 이동하며 작품 감상
- 게스트 관람 — 로그인 없이 누구나 전시관 입장
- 관리자 모드 — 인증 후 작품 등록·수정·삭제
- 작품 업로드 — 사진을 업로드하여 전시관에 반영
- 맞춤형 액자 — 가로·세로·정사각형 및 S/M/L/XL 크기 선택
- 자동 전시 — 빈 벽면에 작품 자동 배치
- 작품 감상 — 작품 확대 및 상세 정보 확인

🛠️ 기술 스택

구분 기술
Frontend React, TypeScript, Vite
3D Graphics Three.js, React Three Fiber, Drei
Styling CSS
Backend Supabase
Deployment Netlify

🚀 실행 방법

npm install
npm run dev

한국 전통 문인화의 아름다움을 현대적인 갤러리 공간에 담았습니다.

- 따뜻한 아이보리 벽면과 원목 인테리어
- 통일된 액자 디자인
